# Learning Resources Directory

## About the Project
This project is a simple webpage that organizes useful learning resources into categories. It was created to practise HTML document structure, lists, and hyperlinks.

## What I Practised
- Creating a complete HTML5 document.
- Organizing content with headings.
- Grouping resources using lists.
- Creating hyperlinks with descriptive anchor text.
- Using HTML attributes appropriately.
- Checking links and reviewing document structure.

## Technologies Used
- HTML5

## What I Learned
I learned how to organize related information into clear sections and connect users to other resources through hyperlinks. I also gained more practice building a webpage from a blank file.

## How to View the Project
Open `webdev.html`, depending on the filename used in this project, in a web browser.
